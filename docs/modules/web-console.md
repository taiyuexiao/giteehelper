# 模块：Web 控制台

> 状态：✅ MVP 已实现（2026-09-28 新增仓库全景与权限收敛）
> 最近更新：2026-09-28

## 摘要
React/Vite Web 控制台提供完整管理面：登录、待处理、仓库全景、关系图、模块与契约、联调运行、修复包、规则编辑、用户管理、审计中心和接入设置。日常通知仍以 Gitee/飞书为主，GUI 用于配置和诊断。

侧栏与路由按角色收敛：`规则` 需要 admin/maintainer，`用户`、`审计`、`接入设置` 需要 admin，其余角色直接看不到入口，越权访问会看到「无访问权限」面板而不是空列表。

## 页面
- `/`：Action Inbox、指标、影响与行动；
- `/repo`：**3D 仓库全景**。按负责人分区着色展示仓库当前状态，提交节点带新提交脉冲特效，悬停出摘要卡片、点击打开详情抽屉（提交作用、需求编号、影响模块与负责人、下一步、变更文件、Gitee 链接）；支持全部/仅新提交/仅冲突/未归属筛选、负责人图例多选、关键词搜索与提交数量调节，并提供「补齐提交」手动同步；
- `/graph`：架构总览、影响路径、全部对象三种模式，分层关系图、搜索、类型过滤、来源/置信度；页头可打开独立 Archify 系统架构图 `/architecture.html`；
- `/modules`：模块/契约、路径模式（决定提交能否自动归属）、新建模块、发起联调；
- `/runs`：联调记录、真实/Stub 组合、运行结果；支持 `?run=<id>` 深链，选中项会写回地址栏；契约未通过时提示缺失契约；
- `/repairs`：修复包 diff、测试报告、批准、鉴权下载 diff，以及批准后的「创建 PR」入口（admin/maintainer/reviewer）；
- `/rules`：YAML 规则编辑、启停、dry-run；
- `/users`：角色和 Gitee/飞书身份映射；
- `/audit`：资源/动作筛选；
- `/integrations`：Gitee/飞书连接、Secret Store 配置、项目配置、**WebHook 投递日志**（时间/事件/状态/提交数/影响数/冲突数/说明，无投递时直接给出回调地址配置指引）、提交统计与运行时状态。

## 设计约束
- 运维型界面使用中性色、8px 卡片圆角和稳定表格/网格；
- 图标使用 lucide-react；
- 桌面侧栏、平板双列、移动单列；
- 不把完整代码发送到飞书；
- 页面只显示配置状态，不显示 Token/Secret；Secret 以留空保持不变的方式替换。
- 配置字段使用可聚焦的圆圈问号帮助浮窗，支持 hover、键盘 focus 和 ARIA tooltip。
- 用户页的负责模块/工作项从模块负责人关系自动汇总，过滤示例和旧导入数据。
- 模态框支持 Escape 关闭、打开时聚焦关闭按钮，并带 `aria-modal` / `aria-labelledby`。
- 3D 页面的 `three.js` 与 `3d-force-graph` 通过 `React.lazy` 分成独立 chunk，只在进入 `/repo` 时加载，不拖慢首屏。
- 所有请求失败都会在页面上以错误条呈现；加载态与错误态分离，网络失败不会永远停在「加载中」。

## 验证
- 登录后 10 个页面均可加载（含 `/repo`）；
- 3D 仓库全景在真实 WebHook 数据下渲染提交节点、负责人分区与新提交特效；
- 关系图 DOM、图例、节点详情可见；
- 1280px 视口下页面 `scrollWidth === viewportWidth`，无全局横向溢出；
- Dashboard 显示真实同步 PR 产生的影响；
- 各页面无浏览器运行时错误。
- Archify 架构图通过 `showcase` 质量校验：9/9 检查通过、0 错误、0 警告；自动视觉检查覆盖 1440×900 与 2048×1320 的明暗主题，均无溢出且可读性通过。

## Bug 与问题记录

### BUG-003 帮助浮窗被容器裁剪且层级不足（2026-09-27，已解决）
- 错误行为：WHEN 目标仓库字段打开帮助浮窗 THEN 浮窗被接入设置卡片/页面边界截断，无法覆盖其他组件。
- 期望行为：WHEN 帮助浮窗打开 THEN 系统 SHALL 将浮窗渲染为 fixed 顶层浮层，并根据触发器和视口自动调整位置。
- 不可破坏的行为：WHEN 鼠标悬停、键盘聚焦或触摸点击 THEN 系统 SHALL CONTINUE TO 显示同一份帮助内容并保持字段可编辑。
- 根因：浮窗是字段内部的 absolute 子元素，被父级 `overflow: hidden` 裁剪，且 z-index 低于页面容器。
- 解决方式：通过 React Portal 渲染到 `document.body`，使用 `position: fixed`、最高层级、视口边界计算和动态箭头位置。
- 验证方式：桌面和 319px 窄视口下均完整位于视口内；浮窗父节点为 BODY，无横向页面溢出。

### BUG-002 关系图全量力导向导致信息密度过高（2026-09-26，已解决）
- 错误行为：WHEN 打开包含多事件、多契约的关系图 THEN 力导向布局节点拥挤、边标签互相覆盖，用户无法识别主要影响路径。
- 期望行为：WHEN 用户打开关系图 THEN 系统 SHALL 默认聚焦最新事件的影响路径，并提供全景、搜索、类型过滤和节点检查器。
- 不可破坏的行为：WHEN 用户切换全景或搜索 THEN 系统 SHALL CONTINUE TO 允许拖拽、缩放、查看全部节点和关系置信度。
- 根因：全量节点同时参与力导向布局，事件节点数量增长后边标签和节点标签失去稳定位置。
- 解决方式：改用 React Flow 自定义节点，按人员/模块/契约/场景/事件分层布局；默认聚焦最新事件及其直接关系，边标签移入节点检查器。
- 验证方式：默认视图 12 个可见节点、0 个节点重叠、无浏览器错误；搜索、聚焦、节点检查器和全景模式均可操作。

### BUG-009 节点全白与画面拥挤（2026-09-28，已解决）
- 错误行为：WHEN 打开 `/repo` THEN 所有节点显示为白色圆形、146 个模块挤成一团、图只占画布 1/3。
- 根因有三个：`new THREE.Color("hsl(...)")` 不解析 CSS 的空格分隔语法，解析失败静默变纯白；每个新提交都挂了一个白色加色发光精灵，且脉冲动画的 effect 在重构时被误删，精灵静止糊在节点上；`zoomToFit` 把 146 个文字精灵与装饰气泡算进包围盒，镜头被拉到极远。
- 解决方式：3D 材质改用数字色值；发光改为同色 wireframe 描边环并补回脉冲动画；不再渲染逐模块文字；仓库→模块改写成仓库→负责人枢纽→模块的两级结构；改用按实际投影尺寸计算的取景。

### BUG-008 侧栏比画布高出一大截（2026-09-28，已解决）
- 错误行为：WHEN 打开 `/repo` THEN 画布结束后左侧留下约 580px 空白，接入状态与图例两个面板对应的左侧区域全空。
- 根因：画布高度固定为 `calc(100vh - 260px)`，而侧栏由内容撑开（1321px > 740px）；且侧栏里的「接入状态」直接复用了为全宽设置页写的 `.runtime-grid` 四列布局，在 300px 宽度下被挤成一团。
- 解决方式：画布与侧栏严格等高、侧栏内部滚动；接入状态改用紧凑键值列表；负责人分区改为两列 chip；按实际头部高度重算画布高度，整页不再出现滚动条。

### BUG-007 错误态不可达与请求竞态（2026-09-28，已解决）
- 错误行为：WHEN `/dashboard`、`/graph` 等请求失败 THEN 页面先命中 `if (!data) return <Loading />`，错误条在其后永远不渲染，界面停在「加载中…」；`/audit` 与 `/rules` 的初值是 `[]`，`if (!rows)` 恒假，Loading 永不出现；审计页每敲一个字符就发一次请求，乱序响应可覆盖结果。
- 期望行为：WHEN 请求失败 THEN 页面 SHALL 显示错误信息；WHEN 连续输入筛选条件 THEN 请求 SHALL 做防抖并丢弃过期响应。
- 解决方式：把错误判断前置到加载判断之前，用 `null` 初值表达未加载，审计页加入 250ms 防抖与取消标记。

### BUG-006 下载修复 diff 必然 401（2026-09-28，已解决）
- 错误行为：WHEN 点击「下载 Diff」THEN 使用 `<a href="/api/repairs/...">`，既不携带 Bearer Token 也不带 `BASE_URL`，必然返回 401。
- 解决方式：新增 `downloadFile()`，用带鉴权的 `fetch` 取回 blob 后再触发下载。

### BUG-005 客户端零角色门禁（2026-09-28，已解决）
- 错误行为：WHEN 以 developer 登录 THEN 侧栏仍显示用户/审计/接入设置，可点进 admin 页面并触发写操作，只能拿到服务端英文 `forbidden`。
- 解决方式：侧栏按角色过滤，路由用 `Guard` 包裹并渲染「无访问权限」面板；服务端同时补齐角色校验——`POST /api/runs`、`POST /api/modules/:id/integrate`、`POST /api/repairs/:id/test` 原本只校验登录，现在要求 admin/maintainer/reviewer/developer，observer 为只读；`403` 文案改为中文，前端也不再渲染 observer 点不动的按钮。

### BUG-004 关系图筛选与深链失效（2026-09-28，已解决）
- 错误行为：WHEN 在模块页点击联调 THEN 使用 `window.location.assign('/runs?run=...')` 整页刷新且忽略 `BASE_URL`，而运行页从不读取 `?run=`；3D 图每次输入关键词都会因 `key` 变化整图重挂载并丢失缩放/平移。
- 解决方式：改用 `useNavigate` / `useSearchParams` 打通深链并在运行页写回地址栏；3D 图过滤只更新可见子集，节点对象复用，不再重挂载。

### BUG-001 React Router 缺少 BrowserRouter（2026-09-26，已解决）
- 错误行为：WHEN 登录成功并首次加载控制台 THEN `useLocation()` 抛出 Router Context 错误，页面空白。
- 期望行为：WHEN 登录成功 THEN 系统 SHALL 渲染控制台路由和导航。
- 不可破坏的行为：WHEN 未登录 THEN 系统 SHALL CONTINUE TO 显示登录页。
- 根因：`App.tsx` 使用 `Routes/NavLink`，但 `main.tsx` 未包裹 `BrowserRouter`。
- 解决方式：在 `src/client/main.tsx` 中包裹 `BrowserRouter`。
- 验证方式：重新构建后登录成功，9 个页面均可加载，浏览器错误日志为空。
